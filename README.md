# SHIFT Self-Coach (Accelerate: Communicating with Influence)

A single-file, self-guided influence planning tool by The Coherence Group.
Runs entirely in the participant's browser. No accounts, no tracking, no
data collection: answers exist only while the page is open and are gone
when the tab closes. Participants work in one sitting and print their
influence map.

## Publish with GitHub Pages (about 3 minutes)

1. Log in at github.com, click the + (top right), New repository.
   Name it `shift-self-coach`, set it to Public, click Create repository.
2. On the new repo page click "uploading an existing file", drag in
   `index.html` (and this README if you like), click Commit changes.
3. Go to Settings > Pages. Under "Build and deployment" choose
   Source: Deploy from a branch, Branch: main, folder: / (root). Save.
4. Wait a minute or two. Your live URL appears at the top of that Pages
   screen: https://YOUR-USERNAME.github.io/shift-self-coach/

To update the tool later, upload a new index.html the same way: the URL
never changes.
